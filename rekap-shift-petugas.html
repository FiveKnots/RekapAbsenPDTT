Rekap Shift Petugas

Drop file seperti 050100-2026-11-23.xlsx (sheet DATA REKAM IMEI) → otomatis jadi file rekap DH / PG / SR per petugas.

Drop file .xlsx di siniatau klik untuk memilih file
Aturan shift (irisan masuk shift yang lebih awal): DH 00:00–08:00 (mulai 23:30 hari sebelumnya), PG 08:00–16:00 (mulai 07:30), SR 16:00–24:00 (mulai 15:30). Hitungan = jumlah baris per nipPetugas berdasarkan waktuRekam. Semua diproses di browser, file tidak diupload. Butuh internet sekali untuk memuat library ExcelJS.
